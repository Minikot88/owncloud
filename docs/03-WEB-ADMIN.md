# การใช้งาน Web Admin

## ใช้ทำอะไร

ใช้จัดการไฟล์ การแชร์ ผู้ใช้ กลุ่ม quota และการตั้งค่าผ่าน ownCloud web UI

## ขั้นตอน

### Step 1 — Login และเปิดพื้นที่ที่ต้องการ

เปิด tunnel ตาม [02-ACCESS.md](02-ACCESS.md), เข้า `https://127.0.0.1:8443` แล้ว login ด้วยบัญชีผู้ดูแลที่ได้รับอนุมัติ. เลือก Files สำหรับข้อมูล หรือ Users/Groups/Settings สำหรับการดูแล

### Step 2 — ทำงาน Files และ shares

| งาน | ทำอะไร/เมื่อไร | ทำอย่างไร | ข้อควรระวัง |
|---|---|---|---|
| Upload | เพิ่มไฟล์ที่อนุมัติ | Files > upload | ตรวจ quota และชื่อ/path |
| Download | รับสำเนาที่มีสิทธิ์ | Files > download | เก็บสำเนาตามนโยบายข้อมูล |
| Folder | แยกงานเป็นพื้นที่ | Files > New folder | ตั้งสิทธิ์ก่อนส่งข้อมูล |
| Rename | แก้ชื่อที่คลาดเคลื่อน | `...` > rename | ตรวจลิงก์/ผู้ใช้ที่อ้าง path |
| Delete | ลบข้อมูลที่อนุมัติ | `...` > delete | ยืนยัน owner และ retention |
| Trashbin | ตรวจ/กู้รายการลบ | เปิด Trashbin | อย่ารับประกันการกู้คืนโดยไม่ตรวจ |
| Versions | ตรวจเวอร์ชันก่อนหน้า | เปิด Versions ของไฟล์ | ใช้เฉพาะเวอร์ชันที่แสดงจริง |
| Share | ให้ผู้อื่นเข้าถึง | `...` > share > เลือกผู้รับ/สิทธิ์ | ให้สิทธิ์ต่ำสุดและทดสอบผู้รับ |

### Step 3 — ทำงานผู้ใช้ กลุ่ม quota และ Settings

| งาน | ทำอะไร/เมื่อไร | ทำอย่างไร | ข้อควรระวัง |
|---|---|---|---|
| Users | สร้าง/แก้ผู้ใช้เมื่อได้รับอนุมัติ | เปิด Users | อย่าเปิดเผย credential |
| Groups | จัดสมาชิกตามโครงการ | เปิด Groups แล้วเพิ่ม/ลบสมาชิก | ตรวจผลกระทบต่อ shares |
| Quota | จำกัดพื้นที่ตามบทบาท | Users > quota | ลด quota อาจทำให้ upload ล้มเหลว |
| Settings | ตรวจ/แก้ค่าที่ UI รองรับ | เปิด Settings | เปลี่ยนเฉพาะผ่าน change control |

## ตรวจสอบว่าสำเร็จ

ตรวจว่าไฟล์/โฟลเดอร์ปรากฏใน Files, สิทธิ์ share ตรงตามผู้รับ และ user/group/quota แสดงค่าที่ตั้งใจไว้

## ถ้ามีปัญหา

ตรวจ tunnel ก่อน; หาก upload ไม่ผ่านให้ตรวจขนาดไฟล์และ quota; หากหาไฟล์ลบไม่พบให้เปิด Trashbin; หากสิทธิ์ไม่ตรงให้ตรวจ group membership และ share permissions

## ข้อควรระวัง

> **WARNING:** Delete, Trashbin cleanup และเปลี่ยน share มีผลต่อการเข้าถึงข้อมูล ให้ยืนยันเจ้าของข้อมูลและผู้รับก่อนดำเนินการ

> **WARNING:** ห้ามใช้ web UI เป็นเหตุให้เข้าถึง filesystem หรือ PostgreSQL โดยตรง
